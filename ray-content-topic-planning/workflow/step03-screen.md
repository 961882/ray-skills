# Step 03: 筛选精选

> 执行者：主 Agent
> 输入：20 个候选选题
> 输出：`select_count` 个精选方向

## 执行说明

从候选选题中筛选出 `select_count` 个最值得优先写的方向。

## 筛选标准（按权重）

| 标准 | 权重 | 说明 |
|------|------|------|
| 素材充足度 | 30% | 源文案中有足够的案例/数据/代码支撑完整文章 |
| 转化潜力 | 25% | 读完后读者是否会产生咨询/关注/收藏的行为 |
| 差异化 | 20% | 市面上是否已有类似内容，我写有没有独特视角 |
| 系列价值 | 15% | 是否能和其他精选选题形成递进/互引 |
| 平台匹配度 | 10% | 在目标平台上的内容形态是否适配 |

## 输出格式

为每个精选方向输出：

```markdown
### 精选 {X}：{选题名}（{类型}款）

**定位**：一句话说清这篇文章在系列中的功能
**入选理由**：为什么从 20 个里选了这个
**素材来源**：源文案中的哪些章节可复用
**风险提示**：写这个选题最容易踩的坑
```

## 平衡性检查

精选结果应覆盖至少 3 种类型（热点/实用/争议/系列），不能全是同一类。

## 验证检查点

- [ ] 精选数量 = `select_count`
- [ ] 至少覆盖 3 种选题类型
- [ ] 每个精选都有明确的素材来源
- [ ] 精选之间能形成系列（互相引导）
