# Step 04: 深度拆解

> 执行者：主 Agent
> 输入：`select_count` 个精选方向
> 输出：每个方向的标题 + 文案结构

## 执行说明

对每个精选选题生成完整的"标题 + 文案结构"拆解。

## 每个选题的输出结构

### 4.1 备选标题（A/B 测试）

为每个选题生成 4 个备选标题：

| 编号 | 标题 | 风格 |
|------|------|------|
| X-1 | ... | 叙事型/场景还原型/对比型/… |
| X-2 | ... | ... |
| X-3 | ... | ... |
| X-4 | ... | ... |

**推荐标题**：选出 1 个并说明推荐理由。

### 标题质量标准

- 有画面感或数字锚点，不空泛
- 优先第一人称视角（"我帮…""我用…""我踩了…"）
- 长度适合目标平台（公众号 ≤ 30 字，小红书 ≤ 20 字）
- 避免"教你""深度解析""全面解读"等 AI 味标题

### 4.2 文案结构（树状大纲）

用树状结构展示完整文案骨架：

```
钩子（150-200 字）
├── 场景还原 / 问题切入
├── 转折 / 冲突
└── 承诺 / 悬念

第一部分 · {小标题}（字数）
├── 要点 1
├── 要点 2
└── 要点 3

第二部分 · {小标题}（字数，核心段）
├── ...
└── ...

第三部分 · {小标题}（字数）
├── ...
└── ...

尾段 · 转化（100 字）
├── 轻总结（个人 IP 强化）
├── CTA：轻引导，不卖课
└── 预告下一篇
```

### 4.3 附加信息

- **预计字数**：总字数范围
- **配图建议**：需要什么图（流程图/表格/截图/对比表）

## CTA 风格规则

参见 `reference/definitions/content-dna-rules.md` 中的 CTA 规则。核心：
- 优先"觉得有启发？点个在看"，不要"私信领资料"
- 可以有轻引导（"评论区聊聊""小红书同步图文版"），但不能有卖课味
- 个人 IP 强化放在总结句里，不单独喊口号

## 验证检查点

- [ ] 每个选题有 4 个备选标题 + 1 个推荐
- [ ] 每个选题有完整的树状文案结构
- [ ] 钩子段不超过 200 字
- [ ] CTA 风格符合规则（轻引导，不卖课）
- [ ] 预计字数和配图建议齐全
