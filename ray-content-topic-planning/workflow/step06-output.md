# Step 06: 输出组装

> 执行者：主 Agent
> 输入：全部产物
> 输出：`output/` 下的最终文件

## 执行说明

将前 5 步的产物组装为最终输出文件。

## 输出文件清单

| # | 文件 | 条件 |
|---|------|------|
| 1 | `{output_dir}/YYMMDD-选题｜标题｜结构.md` | 始终输出 |
| 2 | `{output_dir}/YYMMDD-历史文案分析与重新评分.md` | 仅 has_history == true |

## 主文件结构模板

参见 `reference/templates/output-template.md` 获取完整模板。

核心章节顺序：

```markdown
# {源文案标题} · 内容规划

## 一、身份画像
## 二、选题全景（N 个候选）
## 三、多角色推荐度评审
## 四、M 个方向细化：选题 → 标题 → 文案结构
## 五、发布节奏建议
## 六、沉淀为选题库
```

## 发布节奏生成规则

1. 按综合推荐度降序排列
2. 每周发一篇，标注风险等级（🟢/🟡/🔴）
3. 生成 Mermaid 甘特图
4. 附带"写法关键词"列，提醒每篇的叙事策略

## 选题库生成规则

输出为表格，列：选题 ID、关键词、适用场景、推荐度、优先级、风险、状态（默认"待写"）。

## 验证检查点

- [ ] 主文件包含全部 6 个章节
- [ ] 身份画像和身份目标文件一致
- [ ] 评分表使用校准后（如有）的分数
- [ ] 发布节奏和排名一致
- [ ] 选题库条目数 = `select_count`
- [ ] 如有历史文案，第二个文件已输出
- [ ] 文件名日期前缀 = `date_prefix`

## 完成报告

输出完成后，向用户报告：

1. 产出了几个文件，分别在哪
2. 排名 Top 3 选题一句话总结
3. 最大风险项提示
4. 后续建议（开始撰写第一篇 / 补充历史文案）
